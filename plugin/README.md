# Full File Viewer

Discord's text preview only downloads the first 50 KB, then ends with `(2 MB left)`. This plugin loads the rest of the file and shows it in the same preview.

Large files are drawn a window at a time, so a multi-megabyte log does not freeze Vesktop. Press Ctrl+F, or hover the preview and click the search icon, to find text. Copy in that box copies the whole file.

The size limit is in the plugin settings. Close and reopen a file after changing it.
